# مكونات بيئة التطوير الذكية

## وظيفة الشاشة

هذه الشاشة هي نقطة العمل البرمجية الرئيسية. تجمع المشروع والملفات والمحرر وتوجيه الوكيل ومعاينة الهاتف والتحقق من المهمة والسياسات وسجل Git. لا تنفذ تعديلًا مباشرة من أي لوحة؛ الاقتراح يمر بالمراجعة ثم Human Gate.

## رأس بيئة التطوير

يحتوي الرأس على العنوان «بيئة التطوير الذكية»، وصف يشرح أن التغييرات تمر بالسياق والمراجعة، ومجموعة أفعال محدودة. يجب أن يظل الرأس قصيرًا حتى لا يستهلك مساحة العمل.

| العنصر | النص الافتراضي | السلوك |
|---|---|---|
| العنوان | ابنِ وراجع وشغّل المعاينة بثقة | ثابت في العربية |
| الوصف | كل تغيير يمر عبر سياق محدود ومعاينة وdiff وموافقة بشرية قبل الكتابة | توضيح للحدود |
| فتح المحاكي | فتح المحاكي | يظهر `embeddedPreviewPanel` فقط |
| تشغيل المعاينة | تشغيل المعاينة | يفتح المحاكي ويعرض حالة التشغيل المتاحة |
| الإيقاف | إيقاف | لا يقتل process غير موجودة في هذه الشريحة |
| Fast Refresh | Fast Refresh | يعيد عرض الشجرة المضمنة فقط |
| التقاط | التقاط | يسجل حدثًا محليًا إن توفرت capability |

## لوحة توجيه الوكيل

هذه اللوحة يجب أن تكون واضحة وقريبة من بداية الشاشة. هي نقطة إدخال نية المستخدم، وليست نافذة محادثة أو قناة تنفيذ مباشر.

| الحقل | المعرف | النوع | القيمة أو الخيارات |
|---|---|---|---|
| نص التوجيه | `agentInstruction` | textarea | المطلوب من الوكيل بلغة المستخدم |
| نوع المهمة | `agentIntent` | select | مراجعة وتحليل، خطة تنفيذ، شرح الكود، اقتراح diff |
| النطاق | `agentScope` | input | workspace أو مسار نسبي محدد |
| القيود | `agentConstraints` | input/textarea | قراءة محدودة، منع الكتابة، منع التنفيذ، انتظار الموافقة |
| نتيجة المعاينة | `agentCommandPreview` | منطقة قراءة | ملخص التوجيه والنطاق والقيود |
| الحالة | `agentCommandStatus` | نص حالة | لم ترسل، معاينة محلية، مرفوضة، غير متاحة |

| الإجراء | المعرف | النتيجة |
|---|---|---|
| معاينة التوجيه | `previewAgentCommand` | يعرض التوجيه عبر `textContent` ولا يرسله إلى agent أو provider |
| مسح | `clearAgentCommand` | يمسح النص ويعيد القيود الآمنة ولا يغير المشروع |
| حفظ مسودة | `saveAgentDraft` | اختياري لاحقًا، ولا يصبح متاحًا إلا بعقد تخزين واضح |
| إرسال للمراجعة | `submitAgentReview` | لا يفعّل إلا بعد إضافة عقد typed IPC صريح؛ يبقى غير متاح حاليًا |

### قواعد التوجيه

يجب رفض التوجيه الفارغ، وإظهار حد الطول، وعدم تفسير النص كأمر shell. إذا ذكر المستخدم عملية حساسة، يعرض النظام أنها تحتاج مراجعة وموافقة. لا تُضاف أسرار أو ملفات كاملة تلقائيًا إلى التوجيه. يعرض النطاق كمسار نسبي أو اسم workspace، ولا يكشف root path الكامل إلا عند الحاجة المصرح بها.

## مؤشرات الحالة

| المؤشر | الحالة الأولية | الحالات الممكنة |
|---|---|---|
| حالة الوكيل | جاهز للمراجعة | جاهز، يراجع، ينتظر الموافقة، مرفوض، غير متاح |
| المشروع الحالي | Preview ready أو لم يفتح مجلد | جاهز، اختيار مطلوب، مفتوح، فشل |
| الذاكرة | Local-only | محلية، غير مفعلة، خطأ |
| حالة النظام | Healthy | Healthy، تحذير موارد، تشخيص مطلوب |

## مستكشف المشروع

### بطاقة المشروع

تظهر اسمًا ودودًا للمشروع، نوعه، ووضع المعاينة. عند عدم وجود جذر تظهر «جلسة جاهزة · لم يُفتح مجلد بعد». عند اختيار مجلد، يعرض الاسم المشتق فقط، ولا يعرض root path كاملًا في الواجهة العامة.

### شجرة الملفات

| العقدة | البيانات المعروضة |
|---|---|
| مجلد | الاسم، المسار النسبي، علامة الفتح أو الإغلاق |
| ملف | الاسم، الامتداد، المسار النسبي، حالة التحديد |
| ملف محدد | تمييز واضح، مسار في رأس المحرر، زر فتح |
| خطأ | رسالة محدودة وزر إعادة القراءة إن كان متاحًا |

الأفعال المسموحة هي فتح ملف وتحديده. لا يوجد حذف أو إعادة تسمية أو نقل من هذه الشجرة. أي ملف خارج النطاق أو غير قابل للقراءة يعرض كحالة مرفوضة أو غير متاح.

## محرر المستند

| العنصر | الوظيفة |
|---|---|
| تبويب المستند | اسم الملف وحالة fixture أو loaded أو modified |
| مسار المستند | مسار نسبي في اتجاه LTR |
| نوع الملف | TypeScript أو الامتداد المتاح |
| buffer | نص محلي قابل للتعديل، ولا يكتب المصدر تلقائيًا |
| حالة المحرر | fixture/read-only، loaded/proposal only، modified buffer، conflict |
| اقتراح diff | إنشاء proposal مقابل revision وhash المتوقعين |
| diff preview | عرض الأسطر المضافة والمحذوفة والمشتركة bounded |

الربط الحالي يرتكز على `editor.open` أو `file.openText` عند فتح المستند، و`editor.propose` عند طلب diff. لا يظهر زر commit أو save مباشر داخل هذه الشاشة. عند تعارض revision يجب إيقاف الاقتراح وطلب إعادة التحميل.

## المحاكي المدمج

المحاكي مخفي عند البداية. عند فتحه يظهر بجانب المحرر في سطح المكتب، ولا يتحول إلى نافذة تغطي المحتوى. عند الانتقال إلى شاشة أخرى يغلق تلقائيًا.

| العنصر | المعرف | التفاصيل |
|---|---|---|
| لوحة المحاكي | `previewPanel` | حاوية العرض السياقي |
| اختيار الجهاز | `deviceSelect` | Pixel 9، iPhone 16، Android Tablet |
| التدوير | `rotate` | portrait أو landscape |
| المظهر | `theme` | مظهر شاشة الهاتف فقط |
| إطار الهاتف | `phone` | أبعاد متناسبة مع profile المختار |
| شجرة العرض | `previewTree` | عناصر معاينة آمنة ومحدودة |
| شارة النقل | `pill` | embedded أو lightweight_web |
| خصائص الجهاز | `deviceKv` | platform، OS، frame، DPI، safe area، mode |
| سجل الجلسة | `log` | أحداث جاهزية واتصال وحالة، دون أسرار |

| حالة المحاكي | المحتوى |
|---|---|
| مخفي | لا يحجز عمودًا ولا يظهر أي إطار هاتف |
| جاهز | شجرة معاينة، profile، وضع embedded_web |
| يعمل | حالة تشغيل محلية محدودة وسجل حدث |
| متوقف | لا process نشطة ورسالة توقف واضحة |
| غير متاح | «المضيف لا يوفر جلسة معاينة» دون خطأ تقني خام |
| خطأ | رسالة مختصرة مع إبقاء المحرر قابلًا للاستخدام |

المعاينة ليست محاكيًا أصليًا كاملًا ولا يجب أن تدّعي native fidelity. يجب تسمية الوضع compatibility أو lightweight_web بوضوح.

## مراجعة دورة المهمة

| القسم | المحتوى |
|---|---|
| ملخص الحدود | Review-only، لا patch ولا command ولا runtime ولا approval ticket تلقائي |
| ملفات السياق | عدد الملفات أو الأسماء النسبية المسموح عرضها |
| Manifest | عدد العناصر أو حالة عدم توفره |
| الملفات المستهدفة | العدد والمسارات النسبية |
| حالة السياق | ready، blocked، rejected، unavailable |
| الخطة | خطوات مقترحة دون تنفيذ |
| النقد | ملاحظات الوكيل أو النظام إن وصلت |
| الإجراء | مراجعة المهمة الحالية فقط |

العملية الحالية تستخدم `task.preview` عندما يوجد root صالح. إذا لم يوجد root، يجب عرض سبب طلب المجلد وعدم إرسال payload فارغ.

## Terminal Policy

هذه اللوحة ليست طرفية. تعرض حقلي الأمر والوسائط وزر فحص السياسة فقط.

| الحقل | المعرف | القاعدة |
|---|---|---|
| executable | `terminalExecutable` | قيمة واحدة bounded مثل `pwd` |
| arguments | `terminalArgs` | وسائط محدودة منفصلة، اتجاه LTR |
| فحص السياسة | `inspectTerminal` | يستدعي `terminal.inspect` فقط |
| النتيجة | `terminalPolicyResult` | allowed أو denied أو requires_gate مع السبب |

لا تعرض اللوحة زر «تنفيذ». الأوامر المدمجة، shell wrappers، mutation، native، privileged، والأوامر غير المعروفة يجب أن تظهر مرفوضة أو تحتاج بوابة وفق العقد.

## Git للقراءة فقط

| العنصر | المعرف | المحتوى |
|---|---|---|
| Repository | `gitRepoState` | root required أو اسم مختصر |
| Branch | `gitBranch` | اسم الفرع |
| Changes | `gitCounts` | أعداد محدودة للتغييرات |
| تحديث الحالة | `refreshGit` | استدعاء `git.status` |
| قائمة التغييرات | `gitChanges` | مسارات نسبية وحالة مختصرة |
| diff | `gitDiffPreview` | نتيجة `git.diff` محدودة |

لا توجد أفعال commit أو push أو checkout أو reset. عند غياب root تظهر رسالة اختيار مشروع. يجب إخفاء المسارات المطلقة والرموز السرية.

## الأفعال الحساسة داخل البيئة

| الفعل | الحالة |
|---|---|
| قراءة ملف bounded | متاح عبر العقد المناسبة |
| تعديل buffer المحلي | متاح دون كتابة المصدر |
| اقتراح diff | متاح مع hash وrevision |
| كتابة المصدر | خلف Human Gate وعقد مستقل |
| تشغيل أمر | غير متاح من هذه اللوحة؛ Terminal Policy للفحص فقط |
| تشغيل agent loop | لا يبدأ من حقل التوجيه الحالي |
| تشغيل OpenCode أو Hermes أو DeepSeek UI | غير موجود في واجهة Osamah |
