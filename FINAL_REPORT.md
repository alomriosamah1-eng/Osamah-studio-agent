## دراسة Virtual Human / AI Avatar

أُنجزت دراسة موثقة فقط لنظام Virtual Human Assistant داخل Second Brain في `docs/84-virtual-human-research-and-comparison.md` و`docs/85-virtual-human-architecture-and-contracts.md` و`docs/86-virtual-human-licensing-roadmap-and-decisions.md`. تغطي الدراسة المصادر الأولية الحديثة، المقارنة وTop-5 scoring، الفصل بين Character Model وAvatar Runtime وAnimation وFacial Rig وLip Sync وTTS وSTT وWake Word وAgent Brain وDesktop Overlay، وstate machine والعقود المقترحة وVoiceProfile والخصوصية وPerformance Budget وdegradation ladder وRoadmap 0–11 وLicense Matrix.

النتيجة ليست Avatar feature منفذة: لا توجد حزم أو models أو voices أو assets أو audio runtime أو wake word أو overlay، ولم يتغير Electron/TypeScript/typed IPC أو Architecture الحالية لأجلها. التوصية المرحلية هي stack معياري يبدأ static/text أو low-poly WebGL، مع `three-vrm`/TalkingHead و`sherpa-onnx`/`whisper.cpp` كمرشحين يحتاجون benchmark، وتبقى Arabic dialect/Yemeni support وحقوق النماذج والأصوات غير محسومة. يبقى LivePortrait/MuseTalk high-realism مسارًا اختياريًا معزولًا لا يدخل Ubuntu 8GB MVP. التنفيذ متوقف حتى قرار مالك منفصل. commit الدراسة `d47294ed613090bc913ee14d68669621febbccbb` وdocs-close `7ce4d830c4debdc9c65f7d5ad8729f62454dc99f` دُفعا وتحقق local==remote؛ بوابة التحقق محفوظة في `research/avatar-full-gate-output-2026-08-22.txt`.

## External Accounts metadata-only

تسجل الشريحة بيانات provider وlabel وowner وscopes وresourceScope داخل `InMemoryExternalAccountRegistry`، وتعرضها في Control Center عبر `external.account.register` و`external.account.list`. يبدأ السجل بالحالة `disconnected` والموافقة `required` والتحقق `unknown`. يرفض validator الحقول الزائدة مثل token، ولا ينفذ network أو provider call أو filesystem mutation أو approval ticket. نجح full gate بـ`185/185`، و`pnpm build` و`pnpm desktop:smoke` و`pnpm performance:smoke` وSQLite/JSON/diff/secret validation؛ feature `1b7d9df2d997776fe5453c7d8ea7c4e4c8fc3a4b` وdocs-close `903ad33bedead375a29ed855a339e77ad303113b` متحققان local==remote.

## Storage Settings read-only

تعرض الشريحة snapshot التخزين عبر `storage.get`: الذاكرة تظهر `ephemeral_memory`، وSQLite profile يعرض `profileId` و`studio.sqlite` وschema دون كشف `databasePath` أو `lockPath`. تُظهر اللوحة backup/retention/quota كسياسة وحالة فقط؛ لا تبدأ نقلًا أو حذفًا أو restore أو migration destructive. نجح full gate بـ`189/189`، و`pnpm build` و`pnpm desktop:smoke` و`pnpm performance:smoke` وSQLite/JSON/diff/secret validation، وfeature `fa6486a3a14784d03dd00a868fb5e98c4ff4d2eb` دُفع وتحقق local==remote؛ docs-close مستقل قيد الإعداد.

## البحث التقني

تم تثبيت قرارات Mobile Preview على مصادر رسمية ومراجع مفتوحة متعددة. يوضح [React Native Web](https://necolas.github.io/react-native-web/docs/) طبقة التوافق بين React DOM وReact Native، وتوضح [Expo](https://docs.expo.dev/develop/development-builds/introduction/) أن development builds هي المسار المناسب عند الحاجة إلى native configuration. كما يثبت [Fast Refresh](https://reactnative.dev/docs/fast-refresh) و[Metro](https://docs.expo.dev/guides/why-metro/) مسار التحديث والتجميع المعتاد.

يُستخدم [Expo Snack](https://github.com/expo/snack) و[reactnative.run](https://www.reactnative.run/) كمراجع معمارية للـ browser preview فقط. أما Android Emulator فيحتاج graphics/VM acceleration وفق [توثيق Android](https://developer.android.com/studio/run/emulator-acceleration)، وiOS Simulator متاح ضمن macOS/Xcode وفق [توثيق Apple](https://developer.apple.com/documentation/safari-developer-tools/installing-xcode-and-simulators). لذلك لا يساوي Lightweight Preview محاكيًا native ولا يعلن نجاح native modules.

## الحدود الحالية

يوجد الآن Electron shell أولي وtyped preload boundary مع CSP وsender validation وdesktop smoke، وproduction root picker منفذ عبر main-process dialog وcanonical validation ومدفوع عند `197424dc6cbc1f02b92011903f5bbce77e819f6c`.  أضيف BoundedAgentRuntime وProviderGateway وApprovalWorkflow وAgentWorkCycle وPlanner/Critic وlocal provider adapters كـapplication slices bounded؛ لا يوجد بعد model discovery أو quota/circuit breaker الكامل أو terminal sandbox أو Metro process adapter أو Android doctor/ADB أو iOS Xcode adapter.
 المحاكي المدمج الحالي Lightweight Web/Fixture Preview مع `nativeFidelity: compatibility`، وليس React Native native renderer أو Metro runtime حقيقيًا. `preview.openProject` يعمل عبر in-memory typed IPC خلف Electron preload تجريبي، وليس production boundary النهائي بعد.
